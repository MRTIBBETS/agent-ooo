## 2. Shipped changes

* **Core In-Place Scrubbing Engine (`crates/core/src/detox/scrub.rs`, `crates/core/src/detox/mod.rs`, `crates/core/Cargo.toml`):**
  * Moved `tempfile = "3.27.0"` from `[dev-dependencies]` to `[dependencies]` in `crates/core/Cargo.toml` for same-directory atomic temp-file creation (`NamedTempFile::new_in`).
  * Implemented `InPlaceRedactionReceipt`, `resolve_in_place_targets`, and `redact_transcript_in_place` with `symlink_metadata` regular-file checks (rejecting directories and symlinks).
  * Streamed source files line by line via `BufReader::read_line` into a single reusable `String` buffer while computing `blake3` digests on both input and output streams.
  * Preserved clean lines verbatim via `has_secret_candidate` and `contains_json_unicode_escape` pre-checks; redacted JSON string leaves while skipping structural keys (`id`, `tool_use_id`, `uuid`, `parentUuid`, `sessionId`, `type`, `role`, `source`, `status`, `created_at`, `timestamp`), falling back to `redact_secrets_only` on non-JSON lines, and preserving `\r\n`/`\n` endings.
  * When `redactions_count == 0`, drops the temp file without modifying disk state or creating `.bak`. When `redactions_count > 0` and `--backup` is requested, writes a streaming 8 KB `.bak` via `persist_noclobber` with pre-persist and on-disk `blake3` + byte-length verification, preserves permissions, atomically persists the scrubbed file, and stream-verifies the final on-disk digest.
* **Surgical Secret Redaction Helper (`crates/core/src/detox/sanitizer.rs`):**
  * Factored `mask_secrets_cow` shared between `sanitize_content` and `redact_secrets_only` so historical `.jsonl` scrubbing never strips ANSI codes or duplicates regex logic.
* **CLI Integration (`crates/cli/src/lib.rs`):**
  * Added `--redact-in-place` and `--backup` to `Commands::Detox` with `validate_detox_flags` rejecting `--backup` without `--redact-in-place`.
  * Wired `handle_detox_in_place` and `print_in_place_receipt` for both single-session and `--all` machine-wide execution with `HashSet<PathBuf>` deduplication.
* **Unit Tests & Documentation Sync:**
  * Added 6 unit tests in `crates/core/src/detox/scrub.rs` and `test_cli_detox_redact_in_place_flag_parsing` in `crates/cli/src/lib.rs` (and updated `test_cli_detox_all_flag_parsing`).
  * Updated `README.md`, `llms.txt`, and `skills/agent-ooo/SKILL.md` with `ooo detox --redact-in-place --backup` usage and behavior notes.
* **Coordinator pre-commit self-review fix:**
  * Moved the existing-`.bak` check from pre-scan into `create_verified_backup` (invoked only when `redactions_count > 0`) and added `test_in_place_redaction_idempotent_when_backup_already_exists_on_clean_file`, ensuring repeated `ooo detox --all --redact-in-place --backup` sweeps cleanly skip already-scrubbed files even when an earlier `.bak` copy exists.
