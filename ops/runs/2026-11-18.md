## 2. Shipped changes

* **Fast-Path Byte Pre-Filter (`crates/core/src/detox/sanitizer.rs`):**
  * Added `has_ansi_candidate(bytes: &[u8]) -> bool` (`bytes.contains(&0x1B)`) and `has_secret_candidate(bytes: &[u8]) -> bool` (enforcing the 20-byte minimum `SECRET_RE` length bound and single-pass byte prefix checks for `sk-`, `AIza`, `AQ.`, `AKIA`, `gh[pousr]_`, `github_pat_`, `eyJ`, case-insensitive `bearer`, and `-----BEGIN `).
  * Added `contains_json_unicode_escape(bytes: &[u8]) -> bool` (`bytes.windows(2).any(|w| w == b"\\u")`) so raw JSON lines carrying `\uXXXX` unicode escapes that decode into secret prefixes still route through `serde_json::from_str::<Value>`.
  * Updated `sanitize_content` to return `(content.to_owned(), 0)` immediately when neither candidate predicate matches, and to invoke only the matching regex via `std::borrow::Cow::Borrowed`.
  * Guarded `scan_str_into` with `has_secret_candidate` and refactored `scan_transcript_secrets` to reuse one `String` line buffer via `reader.read_line(&mut line)?`, skipping `serde_json::from_str::<Value>` and regex scanning on clean lines without `\u` escapes.
* **Deterministic Equivalence & Release Benchmark Harness (`crates/core/tests/sanitizer_throughput.rs`):**
  * `test_fast_path_candidate_predicates_and_near_misses`: verifies `< 20` byte shortcuts, clean ASCII prose, and near-miss prefixes (`sk-short`, `Bearer tokens`, `github_`, `AKIA123`, `eyJshort`, `high_water_mark`).
  * `test_fast_path_equivalence_across_all_secret_families_and_ansi`: verifies detection and masking across all 11 secret variants plus CSI/OSC ANSI sequences.
  * `test_scan_transcript_catches_json_unicode_escaped_secret_and_tracks_line_numbers`: verifies `\u0073` JSON-escaped Anthropic keys and 1-based physical line tracking across blank lines.
  * `benchmark_sanitizer_clean_and_mixed_throughput`: benchmarks 10,000 clean turns (`3.70 MB`) and 10,000 mixed turns (`1.98 MB` JSONL / `1.97 MB` raw) with deterministic count assertions and `#[cfg(not(debug_assertions))]` release throughput floors (`>= 20.0 MB/s`).
* **Coordinator pre-commit self-review fixes:**
  * Replaced JSON-escaped `\u001b` in the mixed `sanitize_content` benchmark slice with raw `0x1B` bytes and expanded the clean fixture to `3.70 MB` so the benchmark exercises ANSI stripping and multi-megabyte fast-path throughput.
  * Added docstrings (`///`) and `#[inline]` hints to `has_ansi_candidate`, `has_secret_candidate`, and `contains_json_unicode_escape` in `crates/core/src/detox/sanitizer.rs`.
